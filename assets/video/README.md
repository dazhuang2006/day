# 结尾视频目录

生日信读完之后的收尾视频放在这里，**文件名必须是 `finale.mp4`**（或改 `src/config.ts` 里的 `FINALE_VIDEO.src`）。

- 格式建议 **mp4 / H.264 + AAC**，浏览器兼容性最好；分辨率 1280×720 或 1920×1080 都行。
- **文件不存在时游戏照常运行**，会自动跳过，不会报错。
- 播放时游戏音频会**彻底停止**（不只是压低），只留视频原声——因为此时剧情已结束。
- 右下角会出现「跳过 ▸」按钮（默认 3 秒后出现，可在 `FINALE_VIDEO.skipAfter` 调整）。

## 出场方式

信读完后**不会自动播视频**：最后那一页信会留在屏幕上，并出现一个按钮
（文字见 `FINALE_VIDEO.letterButtonText`）。点它才收起信件并开始播放。

## 结尾行为（`FINALE_VIDEO.mode`）

| 值 | 效果 |
|---|---|
| `wait`（当前） | 视频播完 → 进入自由互动。读档重进不会重播 |
| `replace` | 视频就是结尾，播完停在场景里，不进自由互动 |
| `always` | 每次都播（包括读档重进） |
