# 音频目录（可选）

游戏可完全静默运行；即使这里没有任何文件，也不会报错。

如果你想加入背景音乐，把 mp3 放到本目录并按以下命名即可自动播放：

- `morning.mp3`   — 序章（清晨，轻快温暖）
- `garden.mp3`    — 花园（梦幻治愈）
- `orchard.mp3`   — 苹果园（轻松活泼）
- `evening.mp3`   — 傍晚小屋（温柔）
- `surprise.mp3`  — 敲门惊喜（仅在没有 `birthday.mp3` 时作为兜底）
- `birthday.mp3`  — **主题曲：第四章「傍晚小屋」进屋起一直播到终章**（现有《王贰浪 - 把回忆拼好给你》，6:21 循环）

提示 1：文件缺失时，程序会用 WebAudio 合成的轻柔氛围音自动兜底。
提示 2：`birthday.mp3` 存在时，它会从第四章开始一直循环到游戏结束，中间不换曲；
        想恢复"每章一首"就把它删掉或改名。
